# Phase 0 — setup and preregistration

## Objective

Create a stable, inspectable protocol before results can influence design choices.

## Procedure

1. Review `PROTOCOL.md` and the implementation-facing protocol in `docs/`.
2. Name primary and secondary estimands, required arms, exclusion rules, metrics, uncertainty, and
   stopping rules.
3. Assign the protocol a version and freeze date.
4. Record source access terms, timing roles, and hashes without adding source material to Git.
5. Record every post-freeze change as an amendment in `logs/DECISIONS.md`.

## Exit evidence

- Signed-off protocol version and commit SHA.
- Completed M0 milestone review.
- Source registry with no unresolved temporal classification.
- Clean-checkout installation and command smoke test.

## Current state

In progress. The repository scaffold and draft protocol exist, but no frozen preregistration is yet
claimed.
