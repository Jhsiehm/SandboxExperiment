# Phase 5 — analysis, review, and release

## Objective

Turn sealed run artifacts into appropriately bounded findings that another reviewer can reproduce.

## Procedure

1. Verify seals, protocol version, assignments, completion, and deviations before scoring.
2. Compute prespecified weighted aggregate, individual, uncertainty, and missingness results.
3. Run subgroup and robustness analyses only under prespecified disclosure and cell-size rules.
4. Label confirmatory, exploratory, and structural-pilot output separately.
5. Reproduce the tracked workflow from a clean checkout and conduct claims, privacy, license, and
   security reviews.

## Exit evidence

- Analysis manifest linking every table and figure to a sealed run.
- Robustness, missingness, cost, and failure appendices.
- Clean-checkout reproduction log.
- Approved limitation and supported-claims statement.
- Completed M6 and M7 milestone reviews plus a tagged release.

## Current state

Not started. Structural-pilot summary values are diagnostics only and must not be promoted as
research findings.
