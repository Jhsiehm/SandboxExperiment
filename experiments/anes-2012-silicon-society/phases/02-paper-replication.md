# Phase 2 — paper-style replication

## Objective

Reproduce the closest supported version of the published silicon-sampling comparison before adding
the society treatment or forward-prediction claims.

## Procedure

1. Map the ten declared profile variables and `presvote2012_x` target to the registered source.
2. Reproduce the available Study 2 metrics and subgroup tables.
3. Use the official survey weight for population estimates; otherwise label all aggregates
   unweighted and validation-only.
4. Reproduce Study 3's leave-one-question-out logic separately if its 2016 source and target set are
   in scope.
5. Seal predictions before scoring and enumerate deviations from the published methods.

## Exit evidence

- Field crosswalk and source/version record.
- Sealed prediction and evaluation hashes.
- Weighted result tables with uncertainty.
- Deviation and non-replication statement.
- Completed M3 milestone review.

## Current state

In progress. Metric code and a public replication-style input are present, but a checkpointed,
weighted paper-replication report has not been established.
