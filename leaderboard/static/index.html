      How to run
      
          
      
          
        
            
      1. The 2012 library is Wayback with to=20120630. Grow it with psbx corpus build --epoch e2012 --live --max-docs 400. That is not the CC-MAIN-2012 HTML dump (legacy ARC, “check back later”) and not CC-MAIN-2013-20 (May–June 2013).
        2. 
            
      2. Run practice writes a keyword-lookup baseline. No API keys. Cheap. Folder phase1-e2012-smoke.
        3. 
            
      3. Run live mix scores each of the six OpenRouter species once on 1 question (phase2-e2012-openrouter). Needs OPENROUTER_API_KEY. If that key is missing but both Anthropic and OpenAI keys are set, it uses native Claude+GPT instead. It does not fire 12 bodies.
        4. 
            
      4. Run swarm is 12 sequential OpenRouter votes (2 × each species), shared retrieval, median probability (phase2-e2012-swarm-probe). Same key. Keep it at 1 question unless you mean to wait hours (12×50 at 2s/req).

      5. This page never overwrites a different run folder. Pick a run in the dropdown to inspect it.
